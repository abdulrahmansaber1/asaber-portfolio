# IFOE - Franchise Management System

## 🎯 Project Overview

**IFOE** is a comprehensive franchise management platform designed to streamline franchise operations, applicant management, and business partnerships. The system provides a complete solution for managing franchise opportunities, tracking applications, and facilitating communication between franchisors and potential franchisees.

---

## 🚀 Key Features

### 1. **Franchise Management**

- Complete CRUD operations for franchise listings
- Multi-image support for franchise presentations
- Franchise characteristics management (fees, royalties, marketing costs, investment details)
- Franchise type categorization
- Advanced filtering and search capabilities
- Detailed franchise information display

### 2. **Applicant Management System**

- Online application submission with validation
- QR code generation for each applicant
- Applicant status tracking (attended/absent)
- Automated email notifications with QR codes
- Export functionality for applicant data
- Mobile application for staff to manage applicants
- Real-time status updates (manual and automated)

### 3. **Franchise Request Workflow**

- Request submission and tracking
- Request history logging with change tracking
- Status management (pending, approved, rejected)
- User-specific request viewing
- Administrative approval workflow

### 4. **Content Management System**

- Blog post creation and management
- Category organization
- Multi-language support (Arabic primary)
- Latest blog features for homepage
- Keyword-based SEO optimization

### 5. **Partner Management**

- Partner profile creation
- Partnership tracking
- Display on public-facing website

### 6. **User & Authentication System**

- Role-based access control (Admin, User, Employee)
- Secure authentication using Laravel Sanctum
- Profile management
- Password update functionality
- User registration and login

### 7. **Mobile Staff Application**

- Dedicated mobile API endpoints
- Employee authentication
- Applicant management on-the-go
- Status change capabilities
- Statistics dashboard
- QR code scanning integration

### 8. **Administrative Features**

- Dashboard with key statistics (blogs, users, franchises, partners, applicants)
- Contract period management
- Training period configuration
- Equipment cost tracking
- Space requirements management
- Unit management for measurements
- Country management

### 9. **Communication System**

- Contact form with email integration
- Message storage and management
- Automated email notifications
- QR code email delivery

### 10. **Data Export**

- Excel export functionality for applicants
- Structured data export for reporting

## 🛠️ Tech Stack

### **Backend**

- **Framework:** Laravel 11.31 (PHP 8.2+)
- **Authentication:** Laravel Sanctum (Token-based API authentication)
- **Database ORM:** Eloquent
- **API Architecture:** RESTful API with versioning (v1)
- **File Upload:** Intervention Image 3.11
- **QR Code Generation:** Simple QRCode 4.2 & mPDF QRCode 1.2
- **Excel Export:** Maatwebsite Excel 3.1
- **Email:** Laravel Mail with Mailable classes

### **Frontend**

- **Framework:** Next.js (React)
- **Styling:** Tailwind CSS
- **UI Components:** Modern, responsive design

### **Development Tools**

- **Testing:** PHPUnit 11
- **Code Quality:** Laravel Pint (PHP code style fixer)
- **Development Server:** Laravel Sail (Docker)
- **Debugging:** Laravel Pail
- **API Testing:** Faker for test data generation

## 📁 Project Architecture

### **Design Patterns**

- **MVC Architecture** (Model-View-Controller)
- **Repository Pattern** (for data access)
- **Form Request Validation** (32+ dedicated request classes)
- **Service Layer** (for business logic)
- **Middleware** (authentication, admin authorization)

### **Code Quality Standards**

✅ Type-safe code with PHP 8.2+ features  
✅ PSR-12 coding standards  
✅ Comprehensive error handling with try-catch blocks  
✅ PHPDoc comments for all methods  
✅ Secure validation using Form Requests  
✅ Consistent JSON API responses  
✅ DRY principles applied throughout

### **Security Features**

- Token-based authentication (Sanctum)
- Role-based access control
- Mass assignment protection using `$request->validated()`
- SQL injection prevention via Eloquent ORM
- CORS configuration
- Secure password hashing
- Email validation

## 🔐 Authentication Flow

1. **User Registration** → Email validation → Account creation
2. **Login** → Credentials verification → Sanctum token generation
3. **Token-based requests** → Authorization middleware → Resource access
4. **Role verification** → Admin middleware → Protected operations
