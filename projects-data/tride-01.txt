TRide Dashboard - School Transportation Management System
Short Description
A comprehensive web-based dashboard for managing school transportation services, enabling real-time tracking, ride coordination, and administrative oversight of student transportation operations.

Long Description
TRide Dashboard is a full-featured school transportation management platform designed to streamline the coordination between schools, drivers, parents, and administrators. The system provides powerful tools for managing ride groups, tracking trips in real-time, handling payment processing, and overseeing all aspects of student transportation logistics. Built with modern web technologies, it offers an intuitive interface for administrators to monitor operations, manage users across multiple roles, and ensure safe and efficient transportation services. The platform includes multi-language support (Arabic and English), role-based access control, real-time notifications via WebSocket, and interactive map-based tracking features.

Key Features
Real-Time Trip Tracking: Live GPS tracking with Google Maps integration for monitoring active trips and vehicle locations
Multi-Entity Management: Comprehensive admin panels for managing schools, drivers, parents, students, and ride groups
Role-Based Access Control: Granular permission system with custom roles and access levels for different user types
Payment Processing: Integrated payment management system with transaction tracking and payment plans
Live Chat System: Built-in messaging for communication between administrators, drivers, and parents
Trip Scheduling & Management: Create, assign, and monitor scheduled trips with automated notifications
Geographic Organization: Location-based management with governorates and cities for efficient route planning
Multi-Language Support: Full internationalization with Arabic and English language options
Real-Time Notifications: WebSocket-powered instant updates for trip status changes and system events
Advanced Data Tables: Sortable, filterable tables with pagination and export functionality for all data entities
Analytics Dashboard: Statistical overview with metrics, charts, and performance indicators
Request Management: System for handling transportation requests and booking workflows
