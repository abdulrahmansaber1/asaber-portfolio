Project Title
Corevine: Modern Corporate Web Platform & Custom CMS

Project Overview
A high-performance, full-stack corporate web application built with Next.js 15 and TypeScript. This project features a dual-interface architecture: a premium, animated public-facing website and a secure, custom-built Admin Dashboard (CMS). It empowers administrators to manage dynamic content—including blogs, career openings, and portfolio projects—while offering robust SEO management and bilingual support (English & Arabic).

Key Features
Custom CMS Dashboard: A fully functional admin panel (/admin) allowing CRUD operations for Blogs, Careers, Projects, and Admins.
Advanced SEO Management: Dedicated module to customize meta tags, titles, and descriptions for every page dynamically.
Bilingual Internationalization (i18n): Complete multi-language support for English and Arabic, managed via a custom language provider.
Rich Text Editing: Integrated Tiptap editor for creating rich, formatted content for blogs and project descriptions.
Secure Authentication & RBAC: Custom authentication system using JWT and BCrypt with protected routes for authorized admin access.
Premium UI/UX: A responsive, accessible design utilizing Radix UI primitives, Tailwind CSS for styling, and Framer Motion for smooth page transitions and animations.
Dark/Light Mode: Built-in theme switching capability.
